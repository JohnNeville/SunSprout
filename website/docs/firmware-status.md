# Firmware status

A checklist of what the firmware does and whether it has been run on a real board. Hardware
results are on the [Testing status](./testing-status.md) page, and the firmware itself is in
[SunSprout-firmware](https://github.com/JohnNeville/SunSprout-firmware).

| Status | Meaning |
|---|---|
| **Tested** | Worked on a bench board. |
| **Issue** | Misbehaves. |
| **Not yet tested** | No result yet. |

Features not listed here have not been tested.
